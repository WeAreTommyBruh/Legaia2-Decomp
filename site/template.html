Milestones

  1. Identify the compiler doneThe game's code was built with ee-gcc 2.9-ee-991111-01, -O2 -G8. Hundreds of functions compile byte-identical with it.
  2. Rebuild the executable from assembly doneThe whole .text is split per source file and reassembled; the result matches the original byte for byte.
  3. Match functions in C in progressEach function is rewritten until it compiles to the same bytes, then switched over from assembly to C.

Format tools

Besides the code, the repository contains Python tools that read the game's data from your own disc image. None of the game's files are included.

ToolWhat it does
fs_tool.pyList and extract the game's archive straight from the ISO
lzss.pyDecompress .lzs files and archives
pac_tool.pySplit .pac map packages into chunks
tex_tool.pyConvert texture sets to PNG
tmd_tool.pyConvert .tmd models to Wavefront OBJ
adpcm.py, sq2mid.pyAudio streams to WAV; music sequences to MIDI
battle_script.pyBattle script opcode reference and disassembler
mov_tool.py, efp_tool.py, msg_tool.pyAnimation clips, effect packs, message containers
pss_demux.pySplit the movie file into video and audio

Setup

Linux

git clone https://github.com/WeAreTommyBruh/Legaia2-Decomp.git
mkdir -p ~/tools/ee-gcc2.9-991111-01
curl -L https://github.com/decompme/compilers/releases/download/compilers/ee-gcc2.9-991111-01.tar.xz \
  | tar xJ -C ~/tools/ee-gcc2.9-991111-01

# put SLES_50891.ISO in the repository root, then:
python3 tools/asm_build.py all     # rebuild + byte-identical check
python3 tools/progress.py          # PROGRESS.md
python3 tools/report.py            # report/report.json

Windows

You need to install WSL with Ubuntu or Debian, then follow the Linux steps.

Quick way to name an unknown function: read its Ghidra text for the shape (struct offsets, constants such as `0x2f8` = sizeof frame_state_internal, `-2` table version, `0x7ffffff` VLA size rounding) and recall which library file has it.
- **Struct layouts on this target**: pointers are 4 bytes but `long` is 8, so egcs `struct frame_state` is `{void *cfa; void *eh_ptr; long cfa_offset; long args_size; long reg_or_offset[80]; ushort cfa_reg, retaddr_column; char saved[80];}` (748 bytes, `saved` at +668, struct assignment is the 32-byte `ld/sd` loop), `frame_state_internal` adds `saved_state` at +752 (size 760). `struct fde {int length; int CIE_delta; unsigned pc_begin; unsigned pc_range;}`, `fde_vector {fde **array; unsigned count;}`, `fde_accumulator {linear; erratic}`. `get_cie(f) = (char *)&f->CIE_delta - f->CIE_delta`, `next_fde(f) = (char *)f + f->length + 4`. word_type loads are `long` (64 bit): `(void *)(long t = *(long *)p)` gives the `ld; dsll32; dsra32`.
- **`-fexceptions` is the libgcc2 flag** (no tail call, `jal` to a noreturn callee, `abort` wrapper = 4 words). `cfgs.py ADDR` showed it at once (3 words off instead of 54): ALWAYS run `cfgs.py` on a near-structural draft before editing the source. Functions needing it go into `src/units/_unknown_after_shikimi_eh.c` (cflags line in the unit file); `finish.py` ignores cflags, so append by hand: collapse nothing, put `// MATCH func_XXXXXXXX` directly above the function line, give typedefs/aliases a unique `_ADDR` suffix (`__asm__("D_00427EF8")` alias for a shared global with another struct type).
- **GCC builtins that exist in this cc1** (strings in `~/tools/ee-gcc2.9-991111-01/lib/gcc-lib/ee/2.9-ee-991111-01/cc1`): `__builtin_setjmp` / `__builtin_longjmp` (`__sjthrow`: buf[0]=prev, buf[1]=0, `__builtin_setjmp(&buf[2])`, longjmp at the end), `__builtin_unwind_init` (saves every callee-saved GPR/FPR in the prologue), `__builtin_dwarf_cfa()`, `__builtin_dwarf_reg_size(reg)`, `__builtin_extract_return_addr`, `__builtin_return_address(0)`, `&&label` (label address, `lui/addiu` against the function: only these lines differ in `t.sh`, the link resolves them) and `__builtin_eh_return(eh_context, stack_adjust, handler)` with THREE non-constant arguments (a literal 0 argument ICEs). The 748-byte `ustruct2 = *udata` copy is the generated loop. `__throw`: `if (!eh->info) terminate; label: udata = __frame_state_for(&&label, udata); if (!udata) terminate; udata->cfa = __builtin_dwarf_cfa(); ustruct2 = *udata; pc = __builtin_return_address(0) - 1; handler = throw_helper(eh, pc, sub_udata, &udata); __builtin_eh_return((int)eh, udata->cfa - sub_udata->cfa, handler)`; `__rethrow(index)` is the same with `eh->table_index = index` before the label.

  `func_`) -> write the draft with `mk.sh ADDR` (stdin; `@gp(off)` expands to `D_<0x4A7C70+off>`) into `w/<addr>.c` -> `t.sh ADDR [cc xf]` (diff one draft) and `cfgs.py ADDR`
  (all compiler variants) -> `autofix.py ADDR [secs]` (best config, then `stperm2.py` and `stmove.py` statement search) -> `permw.py` via the permuter queue for what is left ->
  `finish.py ADDR...` (tospec -> batch -> emit -> split_units -> fixblocks) -> `asm_build.py all` (must print MATCH) -> `tools/progress.py`, `tools/report.py`,
  `cp report/report.json report/recomp.json` -> commit, push.
- Other helpers: `var.py ADDR tpl.c` (`{{a|||b}}` choice groups), `knob.py`/`knob_all.py` (pass-through params), `retype.py` / `retype2.py` (flip callee void/int), `argperm.py` and
  `argp2.py ADDR CALLEE` (permute where float and int arguments sit in a callee prototype), `scan_cc2.py CCS` (rescore all drafts under other compilers), `ggnear.py K N MAXSIZE`
  + `ggshow.py ADDR` (best Ghidra variant per unmatched function; hand-fix the small diffs), `ggscan.py`, `blockperm.py`, `ggbig.py`, `wipscan.py` / `prepwip.py ADDR...` (score
  and install `wip/*.c`), `hit.py ADDR` (install a permuter `output-0-1/source.c` as the draft), `genvu0.py` (writes `src/vu0_asm.c`), `mkchunks.py ADDRHEX` (candidate lists).
- decomp-permuter: write the current best source to `build/work/w/<addr>.c`, run `python3 permw.py SECS ADDR...` from `build/work` (it reads the draft's own `// compiler:` /
  `// cflags:` lines). `pqA.sh` and `pqB.sh` are two niced workers over `pq.txt` / `pqB.txt` (done lists `pq.done` / `pqB.done`, logs `pq.log` / `pqB.log`, `PSECS=110`).
  Drafts 1-14 words off solve about one time in four (4 hits in the first 19 runs); drafts 15-30 words off almost never (0 in 22). A "HIT" is not always real
  (20d248 was a false positive: the permuter's objdump hid a `lw`/`li` order swap): re-score it with `batch.py`. About 110 drafts are still queued.
- RTL dumps explain scheduling and register diffs. Compile with `-dr -dj -dg -dl -dc -dG -dS -dR -dL` (files `f.c.rtl/.gcse/.greg/.sched2...`). `.sched2` shows each block's
  `Ready list` (best insn is LAST; ties go to the lower LUID); `.greg` lists refs and live_length per pseudo (priority ~ floor_log2(refs)*refs/live_length; ties: higher regno
  allocated first and gets the LOWER hard reg). Example: 167940's `r7` (8 refs, live 118) outranks `n` (3 refs, live 24), the original has the reverse; 2b8ee8's two hoisted
  `lui`s are created in first-use order and the allocator then reverses them.
- `gen_ghidra.py` has passes for 991111-01, 990721, 990721-r5900, 296 and 296-as210 variants; run `GG_NEW=1 GG_JOBS=6 python3 tools/gen_ghidra.py 160` (small functions first; it is slow).
  Raw Ghidra drafts of 400-700 byte functions are 70-150 words off.

## Techniques that paid off

- Callee return types are the biggest cheap knob: declare a callee `int` instead of `void`, or copy its matched definition's type (122710 needed `int func_0012ACB0`;
  2e8b58 needed a void callee declared `volatile short`).
- Callee argument order: pointer before float, and INTEGER ARGUMENTS FIRST, floats after (`func_0029D010(char *, float, int, int)`; `func_0018E438(int, float x9)` fixed the
  rsound family 10ff28/10ff88/110008). For mixed lists the interleaving matters: `func_00155D40(char *, float, int, int, float, float, float, float, float)` matched 155a68
  only with the first float second (`argp2.py` finds such orders).
- Callee prototypes from Ghidra often hide arguments: pass the caller's own parameters through (`f(a,b,c,d)` where Ghidra said `f(void)`) to fix argument copies and prologue
  order (1925f8, 2132e0, 213368, 2c2be0, 235680 needs 11 int params, 165ca0 needs `f(D, b)`).
- Typed vtable structs (`o->vt->fn60((char *)o + o->vt->adj56, 1)`) instead of raw casts.
- `volatile` for flag words and output pointers (stops hoisting and CSE; fixes most scheduler-order near misses). Volatile accesses cannot go into a branch or call delay slot,
  so a store that the original has in a delay slot must be NON-volatile (2cafb8) and a store that must stay in order must be volatile (2bf848 is 4 words off for this reason).
- Separate loop counter (`i = n`), typed struct pointer for a callee-saved base, hidden pass-through parameters when an argument is copied into `$8`/`$7` (unused extra params
  passed through: 2c31b8 needs -fexceptions), pointer parameter plus an `int` copy (`int p = (int)o; ... g(o);`) for the `daddu` copy at entry (215858, 2153c8, 215420).
- Early returns instead of a result variable fix `daddu $2,$0,$0` delay slots; per-failure `if (bad) { DbgPrintf(str, buf); return 0; }` instead of one shared tail lets gcc
  cross-jump the `jal` tail itself (18a918, 18af40); `size = x + 2047; size &= -2048; call(fd);` puts the `and` in the call's delay slot (18a918); `if (c != 0) c = c + 1; else c = name;`
  (same variable in both arms) avoids the `movz` (18af40).
- A switch with one call per case plus `break` (not a shared call after the switch) reproduces per-case constant loads (16ccd0).
- Struct by value: `V3 t; t = v; f(t)` gives the second 12-byte copy on the stack (24cc58); a returned struct needs `V3 t, v; t = f(); v = t;` (24ccd8). Vector copies need an
  8-byte aligned type (`typedef union { long long l[2]; float f[4]; } V4;`), otherwise gcc uses `ldl/ldr` (162520 is still open, 20 words).
- Member-function-pointer calls (`ld -8` + `dsra32`) match with a hand-expanded ptmf: two separate `idx > 0` tests, one for the function and one for the delta
  (`fn = (void (*)(void *))(e >> 32); d = idx > 0 ? (short)e + dl : dl; fn(o + d);`). All matched now except 204a78 (4 words, 990721-r5900) and 214fa8 (untried). Recipe for 175f58/176e10: `switch (state) { case 0: ...; return 2; case 1: ...; return 2; }` with the main body after the switch, `D_004A129C = 1` stored AFTER the index load, a separate temporary for the case-1 result, and `if (p == 0) Dbg(...); return 2;` (not a return inside the braces).
- Overlapping `lw`/`lh` fields reloaded after a store need a union. A pointer in a callee-saved reg may need a `static inline` helper taking `float *v`.
- Separate base variable (`q = SYM; p = q + 8`) stops `-25104 + 8` folding into one `addiu`; one unsigned counter `for (i = 63; (int)i >= 0; i--)` for two loops;
  `p != 0 && n != 0` plus one post-loop `if (p == 0) return 0` for a shared fail block; copy newlib's variable names for newlib code; `x = base; ... q + 6676` needs the base
  in a separate local assigned inside the branch (2533e8, 25d4b0).
- Statement order matters: `v = *p; p++; f(v); i--;` fixed delay-slot order (18d4a8, 990721-r5900 `-fno-thread-jumps`); list unlink `for (; p != 0; p = p[5]) { if (p[5] == n) {...; break;} }`;
  a `key == -1` early return then one loop (2a1df8); `while (p != 0) { if (cond) break; p = p->next; } return p;` for find loops (2175e0); natural source order beats a
  permuter-shuffled one (1f7970); an `if (x) return 1; return 0;` with the compared global copied into a local first fixed the shuffle_ family.
- Bound-checked table getters (`if (a >= 10 || b < 0 || (unsigned)b >= 94) return DEFAULT; return T[b].f;`) need the three tests as one `||` chain with the third unsigned;
  list pops like `t = L.v[L.n--]` and pointer-reusing `a = (char *)*(int *)(...)` fixed register naming (24a190, 223500).
- Array-of-struct getters/setters match with `E *e = &D[idx]; return e->f;` (a plain `D[idx].f` gives a different `mult` operand order); struct stride 472 with a field beyond it:
  `((E *)(D + i * 472))->f`; when the original keeps the symbol separate from a big displacement use a base array with a pointer variable and a large constant index
  (`int *p = D + a * 118; p[1632] = v;`, 29b1a0, 25d7b0). Multi-index tables: `extern E28 D_0062B3D0[][4]` with `D[a][b].f` (2c9bb8..2ca610 family);
  `[A][B][C][D]` arrays of `volatile` structs with gp ints as indexes matched 136650, 1366e8, 136768 (`int z = 0; e->s0 = z; ... n = e; n->s36 = 0`).
- Hardware-register code is mechanical: `#define R(a) (*(volatile unsigned *)(a))`, in asm order. IPU/DMA code matches with `991111-01-as210`. A memory-test loop is
  `while ((R(0x1000a000) & 0x100) != 0) { if (0x1000000 < i++) {...} }` (condition inside `while`, not a read before the loop); `do { v = R(x); } while (v < 0);` gives the
  4-nop wait loop; a store whose address constant is computed per branch needs the store INSIDE each branch of the `if/else` (2bfec0, 2c0978); quadword FIFO writes use
  `typedef int u128 __attribute__((mode(TI)))` (non-volatile source arrays are CSE'd, so a repeated quad source needs `volatile u128` arrays, 2cfcd0). COP2 `cfc2/ctc2` and
  `sync.p` work as `__asm__ volatile("cfc2 %0, $28" : "+r"(t))`; `__asm__ volatile("cache 0x18, 64(%0)" : : "r"(p))` for cache ops.
- Kernel code: `if (s) { do { di; sync.p; mfc0 } while (v & 0x10000); }` and `ei` inline matched 2e60f0, 2e5d30, 1096c0, 2e5fa0, 2edc98, 2e6370; volatile on the gp scalars they touch
  stops delay-slot hoisting (10f268); in a heap-growth routine the store belongs only on the success path (2e5fa0).
- Floats: callees taking floats need real `float` prototypes (21b468); `__builtin_sqrtf` gives `sqrt.s` + NaN check + `sqrtf` call; `(float)(int)(u & 0xffff)` needs a signed int
  (an unsigned one gives the unsigned-convert sequence); float `locals` reused for the product (`g = g * 128.0f * k`) fixed 12a140; 3-operand `mult` (`.word 0x02032818`) is
  what gcc emits for `x * 40` and `a * b * c`.
- GS-packet functions (`sd` constants + `func_00190328`/`func_00190420` calls) are tractable (2975b8, 2a53b0 matched); `long *q` stores; a stack triple `int e[3]` read back
  (247ef8, 22 words off). More at 24bd78 247970 2436f8.
- Ghidra-derived hints: `0x3f000000` float constants -> `0.5f`; offsets in `lb`/`lhu` mean the field types; `ld`/`lq` mean `long long`/`u128`; a 2-word diff with `addiu` vs `ori`
  constants means the number is an address (use a `D_` array); `divu` means unsigned operands; data addresses passed as call arguments need `D_` arrays and code addresses
  `func_XXXXXXXX` symbols (188c70, 2a2ba0); `src/ghidra/ggint_*.c` holds Ghidra bodies with `undefined8` narrowed to `int` (fixed 2e86a8, 2a3ed8, 2c7ec0); explicit per-field load
  temporaries (`u1 = e->a0; u2 = e->a4; ...`) fixed 218738/218978; a `void` function whose early exit returns the zero it just tested (batread_) must not be declared `int`.
- `-fexceptions` (no tail call) fixes calls at the end of rsound/pchevent-style functions (10d748 is 3 words off with it). The permuter's wins were callee/statement
  transformations: `do { ... } while (0);` around a loop or a call (2ec6f0, 2ee3a0), `k = 3; f(b[2], b[k])` (index through a variable, 2ee3a0).
- CD-library family (0x2e9xxx-0x2ec5xx, sceCd-style wrappers: CreateSema + `func_002E8928` request + WaitSema): matched 2ea9f0, 2eabb8, 2eb4c0, 2ebab0, 2eaff8, 2eb368.
  Recipe: `T *t = D_00634280` request block, `S s; s.a[2]=0; s.a[1]=1; s.a[5]=0; sem = CreateSema(&s)`, `r = func_002E8928(...9 args...)`, early `return -11`/`-1`/`-9`
  constants, then `return res`. Name copy: `if ((t->name[0] = name[0]) != 0) { while (++i < 1024) { if ((t->name[i] = name[i]) == 0) break; } }` gives `lbu`+`sll 24`; a
  `c = t->name[0] = name[0]` with `unsigned char c` gives the `daddu` copy instead (2eb4c0). Per function try `func_002E95B0` as `void` vs `int`.
- Same-shape families: `yue_001e9c18` + 6 siblings (`-fno-gcse`, second pointer `q = p`, int `k`), the nayuwin2 slot loaders 1aa160/1aa270/1aa420/1a19b8/1aa050/1a9f20
  (array-of-struct bases `B164 D_..[]`/`B232 D_..[]`, madd), found by grouping unmatched functions by opcode signature. No unmatched function shares an exact
  mnemonic sequence with a matched one any more.

- **Float/int packer functions (no branches, no calls) lift mechanically:** `addiu rB, rIn, imm` bases become `float *p = (float *)(d + imm); int *ip = (int *)p;`, each store
  `o[k] = p[j]` or `(float)ip[j]` in out-offset order (1d953c, 1d9410, 1d95d4 matched first try). `build/work/lift.py ADDR` does it. A last store that is NOT in the `jr` delay slot
  (nop after the jr) is a `volatile` store (1d95d4). Plain-array `for (i = 0; i < 32; i++) if (T[i] == -1) {...; break;}` gives the original's un-strength-reduced slot scan
  (gcc peels the first iteration itself); a do/while with a pointer variable does not.
- **CD request wrappers** (`func_002E95B0(n)`, `D_00634280` request block, `S s; s.a[1]=1`, `func_002E8928` 9 args): typed struct per function, name copies as in 2eb8a0, a
  `buf[i] = c[i]` loop with `unsigned` index when the original uses `sltu`, signed `int` index for the name loops, error returns as plain negative constants
  (`-65536`/`-65540`/`-65537` are `lui 0xffff`/`lui 0xfffe; ori`). Matched 2ebc48, 2ead88, 2ec110, 2ea810, 2ed680, 2ed218, 2ed348. A base symbol `+8` (`D_006357C8`, p = t - 8)
  stops gcc folding the offset. Hex vs decimal: check `addiu` constants with Python (22472 is 0x57C8).
- **Register priority = refs / live length.** If two values swap registers, remove references to the long-lived one: declare a pass-through callee `int f(void)` instead of
  `f(x)` when the original leaves `$4` untouched (2ed218/2ed348 fixed this way); add references to the other.
- `build/work/vr.py ADDR SPEC.json` (new): variant runner with `@@NAME@@` placeholders and a JSON spec (no `{{ }}` brace clashes); `scoreall`-style pass: score every `w/*.c` draft under
  its own header once (664 drafts take 30 s) to find real near misses; many `w/` drafts are STALE (already matched), so filter by `// MATCH` tags first (the "permuter hits"
  2cf4b0/2cf610 were already matched).

- **Block copies (`ldl/ldr/sdl/sdr` or a runtime `or/andi 7` test) are plain C, and 162 unmatched functions (122 KB) contain them.** An unaligned 8/16-byte copy is a struct of
  `char c[8]` / `char c[16]` assigned by value (`*(B16 *)(o + 112) = *(B16 *)p;`): mizuki 1e0150, th_tex 22c0e0, srivus 1891c0, pchsysw 12e040, pchevent 20ce80, 2cf088 matched that way.
  The inlined 96/252-byte copy WITH a runtime alignment test is gcc's builtin `memcpy(dst, src, N)` (declare `void *memcpy(void *, const void *, unsigned);`, char pointers): 2247b0,
  2248a8 matched with it (a non-constant size stays a real call; known 8-byte alignment gives the plain `ld/sd` loop from a struct of `long long`). Still open with this idiom: 2ece08/
  2ed010/2ed418 (one callee-saved register short), 16d030 (struct `S224` copies, 45 words), 20f3f8, 1748c8, 172998, 1703b0, 20c1d8.
- Layout rules that fixed several functions: the original's `bgez/bltz` sense decides which block is written first (flip `if (a) X else Y` to `if (!a) Y else X`; 20dbb8, 1d95d4-style
  tails); an early `return`'s shared epilogue means a single result variable only if the delay slot holds the `lui`/constant (try both); Ghidra drops FLOAT arguments of callees
  (`func_00154268(b, D)` had a hidden float, 20e0d0/20de78) and argument ORDER of a float+pointer prototype matters for delay-slot filling (`(void *, float)` fixed 20de78); a
  global at `lui`+offset that is accessed with several offsets is ONE struct global (`D_0041EFB0.f208`), not several symbols.
- Unit placement: `finish.py`/`emit.py` put everything into the default unit and ignore a `// compiler:` or `// cflags:` line inside a draft (`rs.score` honours it, so the batch output
  prints a misleading config). Strip the header lines from the `w/` draft before `finish.py`, check the printed config, and move a function that needs 990721-r5900 into
  `<unit>_990721.c` by hand (with `// compiler:` at the top of that file); never leave a `// compiler:` line in the middle of a unit file (it switches the whole file; symptom `fptosi`
  undefined). A helper `static`/`inline` definition must not share a line with the function after `// MATCH` (the build takes the first identifier before `(` as the function).
- Search tools in `build/work` (git-ignored, recreate if lost): `vr.py ADDR SPEC.json` (JSON spec with `@@NAME@@` placeholders and lists of alternatives, scores every combination under
  the listed compiler configs, writes the best draft) and `hc.py ADDR SPEC.json ITERS` (hill-climbs the ORDER of independent statements; random order sampling found 202248 where
  hand ordering failed, but it stalls at local minima for 10+ stores: 2a8950, 216d28, 1569c8). Both honour `// compiler:`/`// cflags:` lines of the base text.
- Still stuck after those searches (all queued for the permuter): 192dd0 (2 words, one `ori`/`lw` swap), 187028 (4, float stores after int stores), 2cf5a0 (7), 20bfe0 (8), 2a8950 (6),
  130188 (9), 24ad58 (28: block order of an `|= 0x40` / `&= ~0x40` pair is right only with the original's `beq` sense, not reproduced), 2215a8/221550 (18: the original stores through
  several copies of the entry pointer), 20f250 (sprintf with nine promoted floats, 64 words), 20c700 (20), 20b978 (17: parameter registers swapped).
- More recipes that matched this round: (1) a leaf with several early `return 0` guards whose original shares ONE epilogue is a single `&&` chain with one `return 0` at the end
  (pchevent 20c1d8; early returns gave a different `ld $31` delay-slot layout); (2) a global counter updated at the end (`D = n + 1`) wants a LOCAL copy `n = D;` read first (battle 127000);
  (3) `*p = e | (b | K)` needs a temporary (`t = b | K; *p = e | t;`) or gcc reassociates the constant (2cf228/2cf508); (4) a loop that must stay un-rotated and has several
  statements per element wants an INDEX loop `for (i = 0; i < 4; i++)` with `p = o + i * 96` (shuffle 178038); (5) a 64-bit shift/mask on a value that is later widened:
  `(n << 3)` in int before the `long` add; (6) when a draft differs only in `mflo`/`jr` delay-slot placement try `991111-01-as210` (24f028); (7) a divisor that stays a register with
  a `break 7` check is just `x / 18` here; (8) callee prototypes taking `(void *, float)` vs `(float, void *)` change delay-slot filling (20de78).

  (2cbb80); always re-score with `allcfg`-style full config scan. A permuter output can carry an `inline_fn` helper on the same line as the function: split it out before
  `// MATCH` (see Unit placement above). Keep to at most four niced workers (load average 10 with five).

  late; bone = parent * T * Rz*Ry*Rx; parts with flag 0x01 (no bone slot) are detached debris and start hidden; family motions (ply03e.tmd -> ply03.mov) match by name prefix
  plus slot count; "Pose with animation" must stay on by default. `LegaiaViewer.snapshot()` draws and returns the canvas (handy for contact sheets). Details are in the
  docstrings of `tools/tmd_tool.py` and `tools/mov_tool.py`.
  Model/motion pairing (2026-11 fixes, all in `legaia.js`): variants share one motion file but not its slot count, so `slotsFit` accepts up to 4 parts more than the clip has (mon005i's
  weapon) or any number fewer (mon00x uses 25 of 32 slots) and `alignSlots` hangs extra parts on the last bone of their name group (`ajila03` on the `ajila` chain); a model with no
  same-family file takes the file in its folder whose bone names share the parts' first three letters (`nameAffinity` >= 0.7 and equal slot count: mon013 -> mon012.mov,
  ply06a..y -> ply00.mov, mon41 -> mon041.mov); a `.tms` falls back the same way (mon011e -> mon011.tms). Skinned vertices and clip joints are not always in one space (mon011 is
  shifted by about its root height, mon012a is mon012 at half size), so `fitSkeleton` fits `v = s*joint + o` from the per-bone mean of strongly weighted vertices and `poseWorld`/
  `bindJoints` take it as `conv.cal` / `cal`; `ratio` > 0.8 means the skeleton belongs to another mesh (mon011_, mon011c) and the model shows unposed ("none found"). Meshes are
  double-sided with arbitrary winding (feathers, cloth), so the fragment shader flips normals that face away from the viewer (otherwise a black/white checker) and back-face culling is
